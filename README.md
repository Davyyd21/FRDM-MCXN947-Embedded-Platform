# MCX-Embedded-MultiApp System

A multi-application system developed for the NXP MCXN947 (Cortex-M33) microcontroller, featuring an OLED display, analog sensors, rotary encoders, and DIP switch control.

## Overview
This project implements a Finite State Machine that allows the user to switch between 4 distinct applications using the DIP switches on the NXP shield. 

## Technical Specifications
* **Microcontroller:** NXP MCXN947 Dual-Core Arm Cortex-M33.
* **Peripherals Used:**
    * **LPADC:** Potentiometer, light sensor, and temperature sensor readings.
    * **CTIMER:** Precise event generation for LED timing (Match Interrupts).
    * **I2C (Flexcomm):** Communication with the OLED display.
    * **GPIO & Interrupts:** Direction control via push buttons (Edge Triggering) and quadrature rotary encoder reading.
    * **OLED Display:** Graphical interface for real-time feedback.

## Included Applications

### 1. Circle of LEDs (App 1 - DP1)
* **Functionality:** A LED scroll where the speed is controlled in real-time by a potentiometer.
* **Hardware:** LPADC (Potentiometer) + CTIMER.
* **Logic:** The value read by the ADC is bit-scaled to update the Timer's Match register. The SW1 button changes the direction of travel by toggling the state of a volatile variable within the GPIO interrupt handler.

### 2. Environment Monitor (App 2 - DP2)
* **Functionality:** Displays ambient temperature and light intensity on the OLED screen.
* **Hardware:** LPADC (Temp & Light Sensors) + I2C OLED.
* **Logic:** ADC software triggers are used to sample the sensors at regular intervals dictated by a timer, followed by formatted data display on the OLED.

### 3. Rotary Encoder Control (App 4 - DP4)
* **Functionality:** An initialization animation (successive LED turning off) followed by manual LED control.
* **Hardware:** Rotary Encoder + Interrupts.
* **Logic:** Detects rotation direction by comparing the states of channels A and B at the moment of the interrupt. It includes "run-once" logic for the LED initialization phase.

### 4. Joystick LED Mapper (App 8 - DP8)
* **Functionality:** Lights up the specific LEDs corresponding to the direction in which the joystick is moved.
* **Hardware:** NAV Switch (Joystick).
* **Logic:** Direct reading of GPIO pins (Active Low) and mapping them to the indices of the LED structure array.

## Project Structure
* **/source** - Contains the main logic (led_blinky.c, pin_mux.h) and interrupt management.
* **/board** - Pin and peripheral configuration files generated by NXP Config Tools.
* **/drivers** - SDK drivers for MCX-specific peripherals.
